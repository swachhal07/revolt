Board and management portraits go here.

Name them by the person's slug in src/data/leadership.js — e.g. moti-lal-dugar.jpg.
Then import the file in that data module and set it as that person's `photo`.

Shoot or crop to 3:4 portrait, head and shoulders, at least 900x1200. The plate
crops with object-top, so leave room above the head rather than below the chin.
